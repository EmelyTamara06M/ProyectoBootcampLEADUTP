## 💻 ¿De qué trata y qué hace este proyecto?
Consiste en el desarrollo y despliegue de una aplicación web construida en Python y alojada en Azure App Service. 
Su objetivo principal es demostrar cómo conectar una aplicación a un Azure Key Vault de manera completamente segura y sin exponer credenciales 
en el código fuente. Para lograrlo, la aplicación utiliza una Identidad Administrada asignada por el sistema, la cual se autentica en Azure y 
utiliza controles de acceso basado en roles (RBAC) para obtener permisos de lectura. Una vez que ya ha sido validado con éxito, la aplicación web recupera 
exitosamente un secreto llamado "mensaje" almacenado en el Key Vault y lo muestra directamente en el navegador. 🔐✨
